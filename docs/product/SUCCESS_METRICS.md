# Success Metrics

- Activation-to-first-useful-render latency.
- Provider connection success by supported Codex version.
- Percentage of snapshots with resolved hierarchy/status/usage.
- Extension host CPU, memory, and webview frame stability.
- Crash-free sessions and parser error rate.
- Accessibility gate pass rate.
- Privacy: zero unapproved outbound requests and zero sensitive fields crossing the webview boundary.

Marketplace installs/stars are adoption signals, not substitutes for reliability.
