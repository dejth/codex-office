# Roadmap

## v0.1 — Foundation and observer prototype

- Validate current Codex integration with sanitized fixtures.
- Render main/nested agent tree and robust connection states.
- Office/Meter sidebar switch and basic inspector.
- Reported per-thread usage with provenance copy.
- CI, tests, VSIX packaging, privacy review.

## v0.2 — Living office

- Deterministic sprite state machine, room layout, reduced motion.
- Richer status mapping and approval/error notifications.
- Visual regression and performance budgets.

## v0.3 — Usage history

- Local session index, daily views, export, retention controls.
- Proven deduplication strategy and recovery after restart.

## v0.4 — Marketplace beta

- Publisher assets, clean-profile QA, public documentation, beta release.

## v1.0 — Stable Codex Office

- Defined compatibility policy, migration policy, complete accessibility audit, stable public configuration, and incident/rollback process.

Other providers and agent controls require post-v1.0 product decisions.
