# Vision

Codex Office makes invisible multi-agent work legible and delightful. Developers should be able to glance at a VS Code sidebar, understand who is working on what, notice blockers, and see honest usage information without sending private development activity anywhere.

It is for individual developers first. It will not become employee surveillance, an unverifiable billing calculator, or a generic multi-provider dashboard before it is excellent for Codex.

The personality is warm pixel-office charm layered over rigorous data provenance and accessible fallback UI.
