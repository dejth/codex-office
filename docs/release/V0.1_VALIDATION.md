Status: 0.1.0 beta published after engineering, compatibility, and human
Marketplace gates passed

authorize future publication, tagging, pushing, or Marketplace mutation.

The candidate passed the isolated lifecycle on both the declared-minimum line

## Deterministic gates

```bash
pnpm check
pnpm audit --prod
pnpm exec vsce package --out artifacts/codex-office-0.1.0.vsix
node scripts/check-budgets.mjs \
  --dist dist \
  --vsix artifacts/codex-office-0.1.0.vsix
node scripts/smoke-clean-profile.mjs \
  --vsix artifacts/codex-office-0.1.0.vsix
shasum -a 256 artifacts/codex-office-0.1.0.vsix
```

The budget check enforces these candidate ceilings:

| Artifact                 |       Maximum |
| ------------------------ | ------------: |
| Extension host bundle    |       140 KiB |
| Webview JavaScript       |       350 KiB |
| Webview stylesheet       |        20 KiB |
| Nine emitted status PNGs | 600,000 bytes |
| Complete `dist` tree     |         1 MiB |
| VSIX                     |       700 KiB |

The VSIX inspection rejects TypeScript, source maps, tests, tasks, docs, raw
generation art, and production source PNG duplicates. Its JSON output records
the candidate SHA-256 checksum.

## Clean-profile lifecycle

`smoke-clean-profile.mjs` creates unique temporary user-data and extension
directories. It never reads or writes the normal VS Code profile. The script
installs the candidate, verifies its ID/version, exercises the process-scoped
disable option, uninstalls it, verifies absence, and removes the temporary
profile.

Upgrade evidence requires a genuine older baseline VSIX. Without one, upgrade
remains explicitly untested rather than simulated by reinstalling the same
version.

The command-line smoke does not claim automated visual interaction with a
running sidebar. Activation, rendering, focus, themes, zoom, and reduced motion
remain separate test and human-review evidence.
