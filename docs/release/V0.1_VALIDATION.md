## Deterministic gates

```bash
pnpm check
node scripts/check-budgets.mjs --dist dist
pnpm exec vsce package --out artifacts/codex-office-0.0.1.vsix
node scripts/check-budgets.mjs \
  --dist dist \
  --vsix artifacts/codex-office-0.0.1.vsix
node scripts/smoke-clean-profile.mjs \
  --vsix artifacts/codex-office-0.0.1.vsix
```

The budget check enforces these candidate ceilings:

| Artifact                 |       Maximum |
| ------------------------ | ------------: |
| Extension host bundle    |       100 KiB |
| Webview JavaScript       |       350 KiB |
| Webview stylesheet       |        20 KiB |
| Nine emitted status PNGs | 160,000 bytes |
| Complete `dist` tree     |       550 KiB |
| VSIX                     |       350 KiB |

The VSIX inspection also rejects TypeScript, source maps, tests, tasks, docs,
raw generation art, and production source PNG duplicates. Its JSON output
records the candidate SHA-256 checksum.

## Clean-profile lifecycle

`smoke-clean-profile.mjs` creates unique temporary user-data and extension
directories. It never reads or writes the normal VS Code profile. The script:

1. installs the candidate;
2. verifies the installed extension ID and version;
3. exercises VS Code's process-scoped `--disable-extension` option;
4. uninstalls the extension and verifies its absence; and
5. removes the temporary profile unless `--keep` is explicitly supplied.

Upgrade evidence requires an older baseline VSIX:

```bash
node scripts/smoke-clean-profile.mjs \
  --baseline-vsix artifacts/codex-office-0.0.0.vsix \
  --vsix artifacts/codex-office-0.0.1.vsix
```

The script rejects a baseline version that is not lower than the candidate.
Without a genuine older candidate, upgrade remains explicitly untested rather
than being simulated by reinstalling the same version.

The command-line disable check proves VS Code accepts the isolated disable
configuration; it does not by itself prove that a running extension host
deactivated. Activation, disposal, sidebar rendering, focus, themes, zoom, and
reduced motion require the integration and visual test evidence recorded below.
