# Pre-release Checklist

- [ ] Scope matches roadmap and changelog.
- [ ] CI and platform matrix pass.
- [ ] Provider compatibility evidence is current.
- [ ] Token labels/provenance are accurate.
- [ ] Privacy, threat model, dependency, CSP, and package-content review pass.
- [ ] Accessibility and reduced-motion checks pass.
- [ ] VSIX installs/uninstalls cleanly in a fresh profile.
- [ ] README/listing screenshots and limitations are current.
- [ ] Version, tag, artifact name, and checksum agree.
- [ ] Rollback owner and path are known.
- [ ] Human explicitly approves Marketplace publication.
