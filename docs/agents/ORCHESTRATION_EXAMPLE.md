# Orchestration Example — v0.1 Provider Slice

## Wave 1 — parallel discovery

- Protocol researcher verifies current Codex fields and produces sanitized fixtures plus ADR.
- UI agent prototypes Office/Meter/Inspector using existing synthetic domain fixtures.
- Release agent validates package metadata and Marketplace checklist without publishing.

## Wave 2 — contracts

- Domain agent finalizes hierarchy and usage invariants from accepted evidence.
- Extension agent versions the sanitized webview message schema.

## Wave 3 — implementation

- Provider agent maps accepted fixtures to domain snapshots.
- Domain agent implements hierarchy and accounting.
- Extension agent connects provider snapshots to the webview.
- UI agent replaces prototype fixtures with the message store.

## Wave 4 — independent verification

- Reviewer checks privacy boundaries, malformed data, nested hierarchy, usage provenance, accessibility, lifecycle cleanup, and package contents.
- Coordinator integrates fixes and runs all gates.

## Wave 5 — human-controlled release

- Release agent builds candidate VSIX and checksum.
- Human tests a clean profile, approves the protected environment, and initiates Marketplace publication.
