# Contributing

Thank you for helping build Codex Office.

1. Discuss substantial changes in an issue first.
2. Read the root and nearest nested `AGENTS.md`.
3. Branch from `main` using `feat/`, `fix/`, `docs/`, or `chore/`.
4. Keep pull requests focused and include tests.
5. Run `pnpm check` and complete the pull request template.
6. Use Conventional Commits, for example `feat(meter): show reported output tokens`.

No contributor may add telemetry, remote services, or behavior that controls Codex sessions without an accepted design decision and maintainer approval.
